# Maze-Solver DOX Context

## Role & Scope
Autonomous Micromouse Maze Solver core algorithmic engine, simulation harness, and physical execution planner for MMRC26 (HTU IEEE RAS 2026).

## Durable Principles
1. **Edge-Based Wall Single Source of Truth**: Walls are stored on shared boundaries (`horizontal_walls`, `vertical_walls`) to eliminate cell desynchronization.
2. **Start-Corner Agnostic**: Must function identically regardless of which corner `(0,0)`, `(0,9)`, `(9,0)`, `(9,9)` serves as the start cell.
3. **Pure Module Isolation**: The navigation core accepts abstract sensor inputs and outputs motion commands without any knowledge of underlying hardware or simulator runtime.
4. **Scoring Optimization**: Architecture optimizes for high repeatable runs within the 480-second match window.
