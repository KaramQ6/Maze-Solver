# MMS — سرعة الروبوت ونقطة البداية

النسخة المخصصة مبنية من [mackorone/mms](https://github.com/mackorone/mms)،
ومربوطة بخوارزمية `mms_main.py`.

## التشغيل

افتح `launch_mms.bat` من جذر المشروع. الملف التنفيذي المستخدم:

```text
tools/mms/bin/mms.exe
```

إذا النسخة ما انبنت بعد، شغّل من جذر المشروع:

```powershell
python tools/mms/build_mms.py --setup
```

السكربت ينزل Qt 6.8.3 وMinGW 13.1 داخل `tools/mms/sdk/`، ويبني البرنامج
وينسخ مكتبات التشغيل إلى `tools/mms/bin/`. يحتاج Git وPython 3.11+ واتصال إنترنت
للتجهيز الأول. للبناء اللاحق:

```powershell
python tools/mms/build_mms.py
```

المسارات العربية مدعومة باستخدام حرف قرص مؤقت أثناء البناء. السكربت يفك الربط
لما يخلص؛ تشغيل البرنامج النهائي ما يحتاج Qt SDK ولا حرف القرص المؤقت.

## إعداد الخوارزمية

من قائمة **Mouse** اختار `MMRC26`. إذا مش موجودة، اضغط زر `+` وأدخل:

| الحقل | القيمة |
|---|---|
| Name | `MMRC26` |
| Directory | المسار الكامل لجذر المشروع |
| Build Command | اتركه فارغاً؛ الخوارزمية Python |
| Run Command | `python mms_main.py` |

إذا بتستخدم البيئة المحلية، خلي **Run Command**:

```text
.venv\Scripts\python.exe mms_main.py
```

اضغط **Run** لتشغيل الخوارزمية.

## تغيير البداية — Set Start

- **X**: رقم العمود، من اليسار، ابتداءً من صفر.
- **Y**: رقم الصف، من الأسفل، ابتداءً من صفر.
- **Heading**: `North / East / South / West`.
- اضغط **Apply** لحفظ الاختيار. المربع المختار يظهر بعلامة `S:N` أو الاتجاه المختار.

مثلاً على متاهة `10×10`: `(0,0)` أسفل اليسار، و`(9,9)` أعلى اليمين.
الواجهة تمنع اختيار إحداثيات خارج المتاهة، وتحفظ البداية لكل ملف متاهة بشكل مستقل.
إذا تغير حجم ملف المتاهة وصار الاختيار المحفوظ خارج الحدود، تستخدم البداية الافتراضية.

إذا غيرت البداية خلال جولة شغالة، البرنامج يعيد تشغيل الخوارزمية من المكان الجديد.
الرجعة للبداية وجولة السرعة وزر **Reset** يستخدموا نفس المكان والاتجاه.
إذا البداية داخل الهدف نفسه، الخوارزمية توضّح أنه ما في مسار بداية-هدف لتنفيذه.

## معايرة السرعة — Robot Speed

`ESP32-C3` هو المعالج؛ ما إله سرعة حركة ثابتة. عشان المحاكاة تقارب الروبوت الحقيقي،
أدخل زمن حركته المقاس على الأرض:

| الإعداد | القياس المطلوب |
|---|---|
| Search: one cell | زمن الحركة من مركز خلية لمركز التالية أثناء الاستكشاف |
| Speed run: one cell | زمن نفس الحركة بإعدادات جولة السرعة |
| Turn: 90 degrees | زمن لفة 90° في مكانه |

المسافة بين مركزي خليتين **192mm**: داخل الخلية `180mm` + سماكة الجدار `12mm`.
قِس عدة محاولات وخذ متوسطها، شاملاً بدء الحركة والفرملة. إذا عندك السرعة المتوسطة
بالمتر/ثانية بدل زمن الخلية، احسب:

```text
cell_seconds = 0.192 / velocity_mps
```

الواجهة تعرض السرعة المكافئة للقيم المدخلة. فعّل **Values measured on the robot**
بعد إدخال قياسات فعلية، واضغط **Apply**. القيم محفوظة بين مرات تشغيل البرنامج.

القيم الافتراضية `0.500s` للاستكشاف، و`0.300s` لجولة السرعة، و`0.250s` للفة
هي قيم تجريبية **غير معايرة**. مش قياسات لروبوت الفريق ولا مستنتجة من قيم PWM.

التشغيل بسرعة زمنية **1x**. الحركة والرسم والـ `ack` يتبعوا توقيت الحركة المختارة؛
ممكن يزيد زمن التنفيذ الكلي قليلاً بسبب حساب الخوارزمية وتبادل الأوامر وجدولة Windows.
هذا نموذج زمن الحركات، مش نموذج كامل لتسارع المحركات أو انزلاق العجلات.

تقدر تغير القيم أثناء التشغيل: الحركة الحالية تكمل بتوقيتها السابق، والجديدة تستخدم
القيم الجديدة. **Pause** يجمّد تقدم الحركة. الزمن المكتوب بنهاية جولة السرعة هو
زمن الساعة الفعلي، ويشمل التوقف المؤقت وتبادل الأوامر.

## الاختبارات وإعادة البناء

```powershell
python -m pytest -v
python tools/mms/build_mms.py --test
```

اختبارات البرنامج تعمل بإعدادات مؤقتة منفصلة، وتتحقق من التوقيت، والحفظ، و`Pause`،
و`Reset`، وتغيير البداية أثناء التشغيل، وتشغيل الخوارزمية الفعلية.
اختبار متاهة المسابقة الإضافي يستخدم `mazes_num/mmrc26_10x10/mmrc26_10x10_seed_17.num`
إذا موجود. تقرير الاختبارات وصور الواجهة محفوظة في:

```text
tools/mms/build/tests/native-results.txt
tools/mms/build/screenshots/
```

مصدر MMS مثبت على `4ed1df48c5223b6b8b422d6e6cf2569ef47d8d8c`.
التعديلات محفوظة في `tools/mms/patches/mmrc26.patch`، والإضافات في
`tools/mms/extensions/`. مجلدات المصدر المنزّل والـ SDK والناتج ملفات مولّدة
ومتجاهلة في Git. ترخيص MMS الأصلي مرفق مع الناتج باسم `LICENSE.mms.txt`.
